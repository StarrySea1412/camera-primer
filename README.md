# 咔嚓！光是怎么变成照片的 · 相机科普手册

## 五段互动

1. **暗箱** —— 拖物距、切换针孔/凸透镜，看倒像怎么来、失焦模糊圈怎么出现
2. **光圈** —— 九片叶片真实结构（圆盘挖正九边形通光孔），f/1.4→f/16 每档进光 ÷2，右侧景深画面对比
3. **快门** —— 焦平面快门两道帘幕赛跑，1/8000s 时曝光发生在一条缝扫过的过程里（运动扇叶被「切」弯）
4. **ISO** —— 同一幅画，噪点随增益爬上来（确定性伪随机图案，可复现）
5. **曝光三角** —— 三个滑杆联动取景器：过曝/欠曝指针 + 慢门拖影 + 高 ISO 噪点，三个代价同屏
